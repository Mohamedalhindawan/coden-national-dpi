# CODEN DPI reference registry — V4.0

**Status:** Scaffold, not an approved national DPI inventory.

## Source rules
- A DPGA registry entry is not necessarily installable software; classify software, open data, AI system, open content, standard, API or infrastructure separately.
- Do not assert a fixed count of DPGA entries without a source snapshot, URL, retrieval date and documented counting rule.
- Do not claim adoption, government authorization, deployment or integration without evidence.
- Maintain separate records for the planned 80 domains and candidate components.
- Each candidate must pass license, maturity, security, localization, data protection, accessibility, interoperability, total cost and ownership evaluation.

## Required evidence
Source URL, snapshot date, maintainer, license, deployment status, integration test, accountable owner and review decision.
