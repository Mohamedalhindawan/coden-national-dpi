# Skill: Typography & Layout Engineering

## Purpose
Ensure consistent, readable typography and page composition across the CODEN document set.

## Procedure
1. Select fonts that support required languages and are licensed/available for embedding.
2. Define heading/body/caption/code/table styles and a limited type scale.
3. Set grid, margins, spacing rhythm, line length, alignment, and column rules.
4. Support Arabic RTL and English LTR correctly, including mixed-direction labels and numerals.
5. Prevent widows, orphans, awkward line breaks, cramped tables, and clipped text.
6. Check hierarchy at actual viewing size, not only zoomed in.

## Acceptance criteria
Consistent typography, correct bidirectional text, comfortable line lengths, predictable spacing, and no overflow.
