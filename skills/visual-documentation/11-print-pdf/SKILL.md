# Skill: Print & PDF Production

## Purpose
Produce reliable, high-quality PDF deliverables for screen viewing and physical printing.

## Procedure
1. Confirm page size, orientation, bleed requirements, margins, and intended printer/output.
2. Prefer vector diagrams and real text; rasterize only assets that need raster treatment.
3. Embed fonts where licensing permits and verify glyph coverage.
4. Use appropriate image resolution and compression without visible artifacts.
5. Set metadata, document title, language, bookmarks, links, and page numbering.
6. Render every page after export and inspect for clipping, font substitution, transparency, and RTL defects.
7. Verify file opens and page count matches the source document.

## Acceptance criteria
Correct page dimensions, crisp diagrams, embedded/available fonts, selectable text, working links, and verified page-by-page rendering.
