# Skill: Visual Quality Assurance

## Purpose
Catch visual, content, and export defects before a CODEN artifact is released.

## Checklist
- Correct approved logo and brand tokens
- Consistent page grid, headers, footers, and numbering
- Accurate text, figures, labels, units, and citations
- No invented values, integrations, certifications, or status claims
- Diagrams legible and consistent with architecture source
- Arabic RTL / English LTR rendering verified
- No clipping, overlap, missing glyphs, broken links, or low-resolution assets
- Tables and charts readable at normal scale
- PDF opens, pages render, fonts embed where possible, links work
- Final artifact reviewed page by page

## Process
Run automated checks where available, render every page to images, inspect contact sheets and detailed pages, fix defects, then rerender and verify.

## Release evidence
Record reviewer, date, source revision, export settings, checks performed, and known limitations.
