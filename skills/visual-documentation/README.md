# CODEN Visual Documentation & Design Skills

A reusable skill pack for producing consistent, accurate, publication-ready CODEN enterprise documents, architecture diagrams, dashboards, and PDFs.

## Brand reference
Use the approved CODEN reference image supplied by the project owner as the visual source of truth:
- Lighthouse mark + Coden wordmark
- Deep navy, blue, white, and turquoise palette
- Clean white technical-document pages with navy headings and blue/turquoise diagrams
- Strong grid, thin rules, restrained shadows, consistent page footer
- Aden/Yemen imagery only where it supports the story (especially covers)

Do not invent exact logo geometry, font names, or color values when the source asset/design tokens are unavailable. Extract and document them from the approved source before production.

## Production workflow
Brief and content audit → brand tokens → information architecture → diagrams/layout → visual QA → PDF/export validation → release package.

## Non-negotiable rules
- Factual accuracy takes priority over decoration.
- Never fabricate metrics, integrations, certifications, screenshots, or implementation status.
- Label illustrative dashboards and mockups clearly.
- Keep diagrams editable whenever practical (Mermaid, SVG, source files).
- Keep text as real selectable text; do not rasterize whole pages.
- Use approved logo assets; never redraw or distort the lighthouse mark.
- Separate target architecture from implemented and production-verified capabilities.
- Record source files, versions, page dimensions, and export checks.
