# Skill: Data Visualization

## Purpose
Present data accurately and clearly in CODEN reports and dashboards.

## Procedure
1. Confirm source, owner, period, units, definitions, and data quality.
2. Choose chart type appropriate to the analytical question.
3. Use honest scales, clear axes, labels, and accessible distinctions.
4. Show uncertainty, missing data, and caveats when material.
5. Do not imply causation from correlation or compare incompatible measures.
6. Label synthetic, illustrative, forecast, and target values explicitly.
7. Provide a table or text summary when a chart alone is insufficient.

## Acceptance criteria
Charts are traceable to data; scales are honest; labels and units are present; no decorative distortion.
