# Skill: Enterprise Dashboard Design

## Purpose
Design credible operational and executive dashboards for CODEN products and internal platforms.

## Procedure
1. Define users, decisions, refresh cadence, data sources, and metric owners.
2. Distinguish actual, target, forecast, and illustrative/demo values.
3. Group KPIs by business, product, engineering, security, reliability, AI workforce, and FinOps.
4. Show metric definition, unit, time range, and status thresholds.
5. Use restrained charts and clear labels; avoid decorative gauges and misleading precision.
6. Include empty, loading, stale-data, and error states in UI concepts.
7. Never present mock data as live telemetry.

## Deliverables
Dashboard information architecture, KPI dictionary, wireframe, and visual specification.

## Acceptance criteria
Every KPI has a definition and provenance; illustrative data is labeled; dashboard supports a real decision.
