# Skill: Design Systems Engineering

## Purpose
Build reusable visual components so all CODEN materials remain consistent and maintainable.

## Procedure
1. Define tokens for color, typography, spacing, radius, borders, shadows, and iconography.
2. Create reusable components: title bars, section headers, KPI cards, tables, callouts, diagram containers, footers, legends.
3. Document component anatomy, variants, usage, and accessibility rules.
4. Store source tokens and components in version control.
5. Use semantic token names; avoid scattered hard-coded styling.
6. Version changes and review their effect across all templates.

## Acceptance criteria
One source of truth for visual tokens; reusable components; documented variants; no uncontrolled style drift.
