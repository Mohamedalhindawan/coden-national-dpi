# Skill: Enterprise Document Design

## Purpose
Design polished, navigable enterprise playbooks and technical reports.

## Procedure
1. Define audience, purpose, document hierarchy, page size, and output formats.
2. Build cover, document control, executive summary, contents, section openers, body pages, appendices, and revision history.
3. Establish consistent headers, footers, page numbers, section labels, captions, tables, and callouts.
4. Use A4 portrait for the main playbook unless landscape is required for wide diagrams; use 16:9 for presentation boards.
5. Keep page density balanced and avoid decorative clutter.
6. Include figure/table numbering and cross-references.
7. Verify the table of contents and page references after final pagination.

## Deliverables
Page templates, document outline, reusable components, and export-ready document.

## Acceptance criteria
Clear hierarchy, consistent pagination, readable tables, navigable contents, no clipped content, and consistent CODEN branding.
