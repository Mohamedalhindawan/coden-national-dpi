# Skill: Information Design

## Purpose
Turn complex technical and institutional material into understandable, decision-ready communication.

## Procedure
1. Identify the key message and audience for each page.
2. Separate facts, proposals, assumptions, examples, and future-state targets.
3. Group related information and create a logical reading sequence.
4. Choose the simplest representation: prose, table, flow, comparison, timeline, or diagram.
5. Reduce duplication while preserving important qualifications.
6. Use meaningful labels and concise captions; define acronyms on first use.
7. Check that the page can be understood without relying on color alone.

## Deliverables
Content hierarchy, page storyboard, information model, and visual summaries.

## Acceptance criteria
Every page has one clear purpose; relationships are unambiguous; no unsupported claims or misleading visual emphasis.
