# Skill: CODEN Brand Identity System

## Purpose
Apply one consistent CODEN identity across playbooks, architecture boards, dashboards, proposals, and presentations.

## Reference
The owner-approved CODEN reference image is authoritative for visual direction: lighthouse + Coden wordmark, navy/blue/white/turquoise, clean enterprise layout, and restrained Aden/Yemen imagery.

## Procedure
1. Locate the approved logo and reference artwork in the repository or supplied assets.
2. Inspect and record exact logo variants, colors, typography, spacing, and usage rules. Do not guess missing token values.
3. Create reusable design tokens for color, type scale, spacing, borders, shadows, icon style, and page grid.
4. Preserve logo proportions and clear space; never recolor or distort without an approved variant.
5. Use cover imagery selectively; internal technical pages should prioritize clarity.
6. Check contrast and legibility in both screen and print contexts.

## Deliverables
Brand token file, logo usage guidance, typography guidance, component examples, and a visual reference sheet.

## Acceptance criteria
All pages use the same approved identity; logo is correct; colors and type are consistent; no invented brand assets are presented as official.
