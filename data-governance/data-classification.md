# CODEN Data Classification — Draft Policy

| Class | Examples | Handling |
|---|---|---|
| Public | Approved public documentation and synthetic demonstrations | Review before publication |
| Internal | Non-public operating documents and internal design | Need-to-know access |
| Confidential | Contracts, sensitive security design, private financial information | Restricted access, encryption and retention controls |
| Restricted | Citizen identity, health, beneficiary and payment records | No use in current public prototype; formal legal basis, security and authority required |

Synthetic test data must be demonstrably non-real and must not embed secrets. Data classification is a proposal pending policy approval.
