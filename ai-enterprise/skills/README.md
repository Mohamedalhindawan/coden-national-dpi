## Activation checklist
1. Review the skill instructions against the complete approved V4.0 playbook once committed to this repository.
2. Confirm named human owner, allowed tools and least-privilege access.
3. Run a harmless synthetic-data test task; record observed outputs and failures.
4. Approve a skill version only after security and engineering review.
5. Maintain a versioned registry and changelog; never assume a markdown file provides runtime enforcement.

## Current limitations
- The complete V4.0 master document is not yet committed on `main`; this is a preliminary alignment, not a completed 90-section compliance audit.
- CI, repository branch protection and agent runtime controls are separate implementation work.
- No production credentials, citizen records, financial commitments or governmental authority are provided by these files.
