# CODEN ADR Index

This index lists architecture decisions recorded in this repository. It is intentionally empty of accepted decisions until actual proposals have been reviewed and approved.

| ID | Title | Status | Owner | Date | Related scope |
|---|---|---|---|---|---|
| — | No decision records registered yet | — | — | — | Framework initialized |

## Register a new ADR

1. Copy [template.md](template.md).
2. Assign the next unused four-digit identifier.
3. Complete the context, options, trade-offs and review requirements.
4. Open a pull request and link affected architecture boards and implementation issues.
5. Record the authorized decision and update this index after approval.

See [README.md](README.md) for the lifecycle and governance rules.
