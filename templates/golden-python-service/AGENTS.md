# Agent instructions — CODEN Golden Python Template

- Only work with synthetic data in this starter. Do not add identity, finance, health, government, customer or citizen records.
- Read README.md and docs/PROJECT_SPEC.md before editing.
- One change per PR; add a failing unittest first, implement, and rerun the full local suite.
- Never add API keys, cookies, secrets or provider credentials to code, git or logs.
- Never call paid models, deploy, merge, change authentication, or authorize a production action without separate explicit human approval.
- Keep examples dependency-free, offline by default, and accessible to Arabic/RTL product requirements if adding UI later.
- Report what changed, tests actually executed, limitations and reviewer sign-off required.
