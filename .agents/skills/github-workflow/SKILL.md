# github-workflow

Review Issue #55 and open PRs before starting. Work on a scoped feature branch; never push directly to main. Include tests and evidence in a draft PR. Do not merge, deploy, spend, expand permissions, or handle real citizen data without explicit approval.

## Completion evidence

Record changed files, tests actually run, security considerations, limitations, and next step. Follow the repository root AGENTS.md. This skill does not grant permissions or enable autonomous deployment.
