# security-review

Use synthetic data only. Inspect changes for hardcoded keys, excessive permissions, injection, unsafe network exposure, missing validation, and sensitive logs. Never expose credentials in commits or CI. Report risk, mitigation, and remaining uncertainty; do not claim a full security audit from static review.

## Completion evidence

Record changed files, tests actually run, security considerations, limitations, and next step. Follow the repository root AGENTS.md. This skill does not grant permissions or enable autonomous deployment.
