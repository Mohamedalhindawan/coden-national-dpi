# systematic-debugging

Capture exact failing input, traceback, and expected behavior. Reproduce in a deterministic test, find the root cause, make a minimal fix, and rerun regression checks. Avoid changing unrelated code or suppressing failures.

## Completion evidence

Record changed files, tests actually run, security considerations, limitations, and next step. Follow the repository root AGENTS.md. This skill does not grant permissions or enable autonomous deployment.
