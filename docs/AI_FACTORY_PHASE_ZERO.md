# تجربة مصنع CODEN المحلية

يتلقى المنسق طلباً اصطناعياً عبر واجهة الأوامر. يستدعي فحص الاستقبال والميزانية من PR #118 ثم يختار وصفة `build-summary`. الوصف والعنوان للتوثيق. اختيار الوصفة عبر `recipe`، ومجموعة الإجراءات المدعومة هي `["run_tests"]`. ينتج وكيل البرمجة استعلام SQL يحسب عمليات البناء لكل حالة ويرتّب الصفوف حسب الحالة. يختبر QA الاستعلام على جدول فارغ وسجل منفرد ومجموعة بها حالات متكررة. يُحفظ ناتج كل محاولة في ملف مستقل.

## التشغيل المحلي

من جذر المستودع باستخدام Python 3.12:

```sh
python -m ai_factory.phase_zero
python -m unittest discover -s tests -v
```

المثال في `ai_factory/examples/build-summary.json`. يقبل الأمر أيضاً `--task FILE` و`--output EXISTING_DIRECTORY` و`--attempts 2`. يعيد الأمر مسار مجلد خاص جديد يضم `events.jsonl` و`candidate-1.sql` عند توليده. رمز الخروج 0 يعني أن الناتج جاهز للمراجعة، و1 يعني الحظر أو فشل التنفيذ، و2 يعني خطأ إعداد أو إدخال. الوضع الافتراضي محاكاة حتمية تعمل بالمكتبة القياسية حتى عند غياب المفتاح.

## العزل والحدود

ميزانية الاستدلال صفر. يستخدم QA قاعدة SQLite جديدة في الذاكرة لكل حالة، مع مفردات SQL محددة وقراءة فقط وحدود لطول الاستعلام وعدد تعليمات SQLite. هذا عزل لتنفيذ استعلام التقرير. دعم شيفرات Python أو shell مولّدة يحتاج إلى بيئة تنفيذ أخرى. لكل طلب محاولة واحدة افتراضياً ومحاولتان كحد أقصى. ينتهي النجاح بحالة `awaiting_human_review`. يراجع الإنسان ملف SQL والسجل قبل أي ترقية عبر آلية المراجعة في المستودع. الإنفاق والنشر وإجراءات الهوية والمدفوعات خارج صلاحيات المصنع.

## قراءة مخرجات Codex عبر Agents API

عند توفر جلسة مستضافة مكتملة أُجيزت بصورة مستقلة، يمكن استخدام ملفها الاصطناعي في مسار QA نفسه. يلزم مفتاح مشروع مخوّل للقراءة، ومعرّفا الجلسة والدورة، وملف نصي UTF-8 لا يتجاوز 4096 بايت في `/workspace/outputs/report.sql`. يعتمد المسار الاختياري على `openai==3.13.0`. بعد تهيئة البيئة والمفتاح بشكل آمن:

```sh
python -m ai_factory.phase_zero --codex-artifact SESSION_ID TURN_ID
```

يستخدم المحوّل واجهتي سرد الملفات وقراءة محتواها في SDK. يتحقق من الدورة والمسار ويعيد فحص المحتوى محلياً. اختبار SDK يستخدم نقل HTTP وهمياً داخل العملية. إنشاء جلسة أو بدء دورة مدفوعة غير متاح في هذه المرحلة. لم يُختبر الوصول إلى حساب حي. لتوسعة المصنع، يمكن تمرير وكيل برمجة يوفّر `mode` و`write()` أو وكيل QA يوفّر `check(query)` إلى `run`.
