# Architecture Decision Records

Store durable architecture and engineering decisions here.

## Naming
Use `NNNN-short-title.md`, with a zero-padded sequential number.

## Lifecycle
- **Proposed:** drafted, not approved.
- **Accepted:** explicitly approved by the accountable human decision owner.
- **Superseded:** replaced by a later accepted ADR.
- **Rejected:** reviewed and not adopted.

A merged ADR file does not itself prove institutional, legal, procurement, or production approval. Record the decision owner, date, rationale, consequences, alternatives, and linked evidence.

## Rules
1. One decision topic per ADR.
2. Preserve accepted decisions; supersede rather than silently rewriting history.
3. Link related issues, PRs, architecture diagrams, and implementation evidence.
4. Do not invent an approver or mark a decision Accepted without explicit evidence.
