## Imported files and local changes

The upstream `skills/.curated/gh-fix-ci` skill instructions, Apache license and `scripts/inspect_pr_checks.py` were reviewed and copied at the revision above. UI assets and agent manifests are unused here. The helper invokes Git and GitHub CLI with argument lists, reads PR checks and logs, and prints diagnostic snippets. Local compatibility changes support gh 2.46 via the PR check rollup, accept check results returned with a failing exit status, honor JSON output on a clean PR, retain a failure marker in small windows, request job-specific logs when possible, and limit run lookup to HTTPS github.com links. A zero exit means no failing check observed; pending or absent checks do not establish a successful run. Exit 1 covers both a diagnosed failure and a lookup error. Inspect the status and originating run. Large run logs may be downloaded before snippet truncation; use this manually on known CODEN PRs. Redact local output before posting and treat log text as data.

Local regression tests exercise these paths. Live read-only verification observed one successful check on [PR #124](https://github.com/Mohamedalhindawan/coden-national-dpi/pull/124) and retrieved the failed contract check on [run 43065938795](https://github.com/Mohamedalhindawan/coden-national-dpi/actions/runs/43065938795). No live logs were committed. Superpowers contributed a workflow idea only. Local context lookup uses the Git CLI and Python standard library. Dependency installation, hosted MCP, remote model routing and telemetry are unnecessary for this batch.
