# CODEN AI Factory expansion

| Milestone | Reuse and boundary | Evidence required to advance |
|---|---|---|
| Local engineering loop | This branch delivers targeted context, TDD, review guidance and GitHub CI diagnosis. Store the spec and acceptance tests with the change; use the ADR index for durable decisions. | Reproducible local benchmark, inspectable PR, passing contract checks, human review. |
| Independent review | Keep the orchestrator, coding and QA stages from #124. Use the review skill and the existing QA profile for a separate read-only reviewer once an environment and quota are approved. Give it the base revision and acceptance test. | Reviewer independently detects a seeded defect, reports its location, and accepts the corrected version. Measure time, false positives and rework. Automated mutation evidence is available today. |
| Specification, memory and specialist roles | Pilot OpenSpec on one real cross-component change. Link requirements to tests and existing ADRs. Add Architecture, Security, Documentation or DevOps profiles individually only for a task with an owner and an otherwise unmet criterion. Preserve human release authority. | One requirement-to-test trace and one useful independently verified finding per proposed role. Consider Serena only when a text lookup misses a cross-file relationship. |
| Bounded parallel / long-running work | Start with #26 DAG, queue, scheduler and recovery implementations. Reconcile them with #124 before choosing an external workflow engine. Run independent tests in parallel locally on synthetic input. | Measure serial versus parallel wall time and overhead. Demonstrate retry after interruption, idempotent writes, cancellation and a global attempt cap before enabling unattended workers. |
| Multiple providers | Start with #26 simulated ModelGateway, #118 budget checks and #124's read-only artifact adapter. Evaluate a local LiteLLM pilot with explicitly approved endpoints and synthetic fixtures. | Explicit approval for destination, classification and spending; pre-call budget reservation, usage reconciliation, policy-preserving fallback, provider terms and audit evidence. Live cost, token counts and reliability remain NOT MEASURED. |
