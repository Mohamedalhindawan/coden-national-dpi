## Audit procedure
1. Obtain the full approved V4.0 text in repository, with provenance and version control.
2. For each section extract precise requirements and acceptance criteria.
3. Inspect code, tests, CI, decisions, approvals and runtime evidence.
4. Assign one accountable human owner and date; link exact commits, PRs and test runs.
5. Have a second reviewer verify evidence before marking Verified.
