# تشغيل وكيل برمجي مجاني من جوال أندرويد — CODEN / تمام

**الحالة:** مسار تجريبي يحتاج أن يفعّله المستخدم بنفسه؛ لم يتم ربط خدمة خارجية بالمستودع بعد.  
**الميزانية:** 0 دولار مبدئيًا. لا نفترض أن الحصة المجانية غير محدودة أو مضمونة في كل بلد.

## المسار المقترح للتجربة: Freebuff Cloud

المشروع يعلن عن خدمة Freebuff Cloud لتشغيل وكلاء على مستودعات GitHub، مع وصول مجاني محدود بحسب المنطقة والسعة الحالية، ودون الحاجة إلى مفتاح API وفقًا لصفحة المشروع. هذا خيار خارجي غير تابع لـ GitHub أو OpenAI، وقد تتغير شروطه أو توفره.

- الموقع: https://freebuff.com/
- مستودع المشروع ومصدر التفاصيل: https://github.com/CodebuffAI/freebuff
- سياسة الخصوصية: افتح رابط Privacy Policy من موقع الخدمة واقرأها قبل ربط المستودع.

## قبل الربط — قواعد الخصوصية والأمان

1. استخدم المستودع الحالي فقط بعد مراجعة الصلاحيات التي تطلبها الخدمة.
2. لا ترفع بيانات مستفيدين حقيقية أو أرقام هوية أو ملفات SFD داخل الخدمة؛ استخدم بيانات اصطناعية فقط.
3. لا تضع مفاتيح API أو كلمات مرور أو رموز وصول في المحادثة أو في ملفات GitHub أو تعليمات الوكيل.
4. ابدأ بمهمة صغيرة على فرع جديد، ولا تسمح للوكيل بدمج التغييرات تلقائيًا في `main`.
5. راجع كل فرق تغييرات (diff) وشغّل GitHub Actions قبل قبول أي Pull Request.
6. لا تسمح للوكيل بتنفيذ نشر إنتاجي أو تغييرات هوية أو مدفوعات أو استحقاق مساعدات أو إعدادات أمنية دون مراجعة وموافقة بشرية.
7. إذا طلبت الخدمة وسيلة دفع أو طلبت صلاحيات واسعة لا تحتاجها، أوقف الإعداد ولا تكمل.

## خطوات التنفيذ من الجوال

1. افتح https://freebuff.com/ في Chrome على أندرويد.
2. سجّل الدخول فقط إذا كانت الخدمة متاحة لك، ثم ابحث عن **Freebuff Cloud** أو خيار ربط مستودع GitHub.
3. اربط GitHub عبر شاشة التفويض الرسمية. اقرأ قائمة الصلاحيات؛ اختر مستودع `Mohamedalhindawan/coden-national-dpi` فقط إن كان خيار تحديد المستودعات متاحًا.
4. إن لم تتمكن من حصر الصلاحيات على هذا المستودع، لا تمنح وصولًا واسعًا قبل فهمه.
5. ابدأ بمهمة مراجعة فقط، دون السماح بتعديلات، باستخدام النص التالي.
6. بعد أن ينجح الاتصال، اطلب من الوكيل إنشاء فرع وPull Request، ثم افحص النتيجة واختبارات Actions بنفسك أو اطلب المساعدة في مراجعتها.
