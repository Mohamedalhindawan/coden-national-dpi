# CODEN Engineering Review Checklist — Draft

- [ ] Change request, scope and acceptance criteria are traceable
- [ ] Tests added first for behavior changes, or reason recorded
- [ ] Relevant test suite actually executed and result linked
- [ ] No secrets or real personal/beneficiary/financial data
- [ ] Security, privacy and authorization impact assessed
- [ ] API compatibility and ADR updates assessed
- [ ] Arabic RTL, accessibility and low-bandwidth impact assessed
- [ ] Dependency/license/supply-chain impact assessed
- [ ] CI checks passed and protected-branch requirements met
- [ ] High-impact changes approved by authorized human
- [ ] Deployment and rollback evidence supplied if applicable

A checked box without a link or reviewer is not sufficient evidence.
