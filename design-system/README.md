# CODEN Design System 1.0 — Foundation

Status: **Draft / visual reference aligned; exact brand tokens pending owner approval.**

This design system is the single starting point for CODEN playbooks, architecture boards, dashboards, proposals, and presentations.

## Visual source of truth
Use the owner-approved CODEN reference image: lighthouse mark + Coden wordmark, navy/blue/white/turquoise palette, white technical-document pages, clean navy headings, blue/turquoise diagrams, thin separators, restrained shadows, and Aden/Yemen imagery primarily on covers.

The reference image is a visual guide, not a substitute for source logo artwork. Do not crop the logo out of a screenshot for production use if a clean vector/raster logo asset can be obtained. Never redraw, distort, or invent official logo geometry.

## Rules
1. Treat token values marked provisional as estimates, not approved brand specifications.
2. Replace provisional colors only after sampling/approval against the original brand asset.
3. Use real selectable text; do not flatten complete pages into images.
4. Keep architecture diagrams editable and validate their technical meaning.
5. Mark sample metrics, UI mockups, and target-state designs as illustrative.
6. Use Arabic RTL and English LTR correctly, including mixed-language pages.
7. Every published artifact must pass the visual QA checklist in `skills/visual-documentation/07-visual-qa/SKILL.md`.

## Versioning
- 1.0: initial foundation, component rules, and editable diagram template.
- Changes to logo, palette, typography, or core components require a documented review.
